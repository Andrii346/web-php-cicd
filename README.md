Навчальний проект для демонстрації роботи CI/CD пайплайну через GitHub Actions.

## Функціонал
- Математичні операції додавання та віднімання (`app/Services/Calculator.php`).
- Автоматичний лінтинг коду за допомогою Laravel Pint.
- Модульні тести на базі PHPUnit.
